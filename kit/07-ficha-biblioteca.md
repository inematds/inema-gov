# 07 · Ficha da biblioteca compartilhada

Quando uma prefeitura resolve bem um problema, outras adaptam sem começar do zero. Só entra o que foi autorizado para reuso — **nunca dados municipais ou pessoais**.

```
Nome da solução: __________________________________________
Problema que resolve (1 frase): ___________________________
Prefeitura de origem: ______________   Porte: [ ] pequeno [ ] médio [ ] grande
Secretaria: ______________

O que está sendo compartilhado:
[ ] ficha do processo (antes e depois)
[ ] critérios de aceite
[ ] código ou configuração
[ ] manual de uso
[ ] checklist preenchido (sem dados pessoais)

Licença / autorização de reuso: ____________________________
Resultado medido: _________________________________________
O que adaptar em outra prefeitura: _________________________
O que deu errado e como resolvemos: ________________________
Contato do multiplicador: __________________________________
```

Modelos candidatos já citados na proposta: manutenção urbana, gestão de frota e ordens de serviço, agenda e informação de serviços, protocolos simples.
