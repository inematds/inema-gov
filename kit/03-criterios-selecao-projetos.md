# 03 · Critérios de seleção dos dois projetos

No fim do mês 1, cada prefeitura escolhe **um projeto interno** e **um projeto para o cidadão**.

## Filtro (todos precisam ser "sim")

- [ ] Resolve um problema que aparece na ficha de mapeamento, com volume real.
- [ ] Cabe em um mês de construção com a equipe do programa.
- [ ] Não decide sozinho sobre direitos, benefícios, saúde, tributos ou sanções.
- [ ] Tem um responsável na secretaria e usuários disponíveis para testar.
- [ ] Não exige trocar um sistema que já funciona.
- [ ] Os dados necessários podem ser usados (ou o teste funciona com dados fictícios).

## Pontuação (para desempatar)

| Critério | Peso | Nota 1–3 |
|---|---|---|
| Impacto no servidor ou no cidadão | 3 | |
| Frequência (quantas vezes por semana) | 2 | |
| Baixo risco | 2 | |
| Reutilizável por outras prefeituras | 2 | |
| Facilidade de medir o antes e o depois | 1 | |

Maior total ganha. Registre os candidatos que ficaram de fora: viram o ciclo 2.

## Exemplos que costumam passar

- Interno: pedidos de manutenção, solicitações de RH, tramitação de documentos.
- Cidadão: registro e acompanhamento de solicitações, calendário de coleta, consulta de serviços.
