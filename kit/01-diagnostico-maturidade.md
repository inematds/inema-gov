# 01 · Diagnóstico de maturidade digital

Responda de 0 a 3 (0 = não existe, 1 = começo, 2 = funciona em parte, 3 = funciona bem). Não é prova: serve para escolher por onde começar.

## Pessoas

| Pergunta | 0–3 |
|---|---|
| Os servidores usam alguma ferramenta de IA no trabalho, com orientação? | |
| Há pessoas que ensinam colegas (multiplicadores informais)? | |
| A liderança reserva tempo para melhoria de processos? | |

## Processos

| Pergunta | 0–3 |
|---|---|
| Os principais processos estão escritos em algum lugar? | |
| Dá para saber em que etapa está um pedido? | |
| Existe medida de prazo ou volume de algum serviço? | |

## Sistemas e dados

| Pergunta | 0–3 |
|---|---|
| Sabemos quais sistemas a prefeitura usa e quem é o fornecedor? | |
| Os sistemas permitem exportar dados ou têm integração (API)? | |
| Os cadastros (cidadão, imóveis, servidores) são confiáveis? | |

## Segurança e governança

| Pergunta | 0–3 |
|---|---|
| Existe encarregado de dados (LGPD) nomeado? | |
| Há regra sobre o uso de IA externa com dados da prefeitura? | |
| Os acessos aos sistemas são individuais e revisados? | |

## Leitura

- **0–12:** começar pelas trilhas 1, 3 e 9; projetos sem dados pessoais.
- **13–24:** seguir o programa padrão; escolher projeto interno com dados próprios.
- **25–36:** acelerar trilhas 6 a 8; considerar integração autorizada no ciclo 2.
