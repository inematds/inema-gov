# 05 · Checklist LGPD e segurança

Antes de testar com dados reais e antes de publicar. Não substitui a análise da assessoria jurídica e do encarregado de dados.

## Dados

- [ ] Sabemos quais dados pessoais a solução usa e por quê (finalidade).
- [ ] Há base legal identificada para cada uso.
- [ ] Usamos só os dados necessários (nada "por via das dúvidas").
- [ ] Nenhum dado pessoal real vai para ferramenta de IA externa sem autorização, base legal e controles.
- [ ] Os testes usaram dados fictícios ou anonimizados.
- [ ] Sabemos onde os dados ficam guardados e por quanto tempo.

## Acesso

- [ ] Cada pessoa entra com o próprio usuário.
- [ ] Cada perfil vê só o que precisa.
- [ ] Senhas e chaves não estão escritas no código nem em documentos compartilhados.
- [ ] Há registro de quem fez o quê (trilha de auditoria).

## Decisão e supervisão

- [ ] A solução não decide sozinha sobre direitos, benefícios, saúde, tributos ou sanções.
- [ ] Onde a IA sugere algo, uma pessoa aprova.
- [ ] O cidadão sabe com quem falar quando algo dá errado.

## Publicação ao cidadão

- [ ] Linguagem simples, testada com quem não é da prefeitura.
- [ ] Acessibilidade verificada (leitor de tela, contraste, celular).
- [ ] Aviso de privacidade publicado.
- [ ] Canal de suporte definido e funcionando.
