## O que é

O INEMA GOV é um programa de formação aplicada para prefeituras. Gestores, servidores e a equipe de TI aprendem a mapear processos reais, simplificar a rotina e construir soluções digitais pequenas, usando inteligência artificial com segurança. Em três meses saem duas soluções testadas: uma para o trabalho interno e outra para o cidadão. Aqui estão o método, as trilhas com cursos abertos do INEMA, os modelos para preencher e o plano dos pilotos.

## O caminho

**MAPEAR → MELHORAR → CONSTRUIR → VALIDAR → OPERAR → MEDIR E MELHORAR**

1. **Abertura:** duas palestras de 4 h — liderança (A) e servidores (B).
2. **Mês 1 — aprender a transformar:** formação, processos mapeados, dois projetos escolhidos.
3. **Mês 2 — melhorar o trabalho da prefeitura:** uma solução interna testada.
4. **Mês 3 — facilitar a vida do cidadão:** uma solução para a população, testada e, se aprovada, publicada.
5. **4º ao 12º mês (programa anual):** novos ciclos, multiplicadores e biblioteca compartilhada.

## Limites

Metas para planejar, não garantias. Sem sistemas completos nem integrações complexas em 90 dias. Sem automação que decida sozinha sobre direitos, benefícios, saúde, tributos ou sanções. Os pontos de governança não substituem a análise jurídica de cada município. Projeto institucional, não partidário.
